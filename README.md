## ✨ 核心特性

- 🎨 **统一美学**：从终端到窗口管理器，全面应用 Catppuccin 配色。
- ⚡ **极速启动**：基于 Openbox + 高度精简的配置，低配/移动设备也能起飞。
- 🐚 **Fish Shell**：提供智能补全、语法高亮与极致的交互体验。
- 🛠️ **自建工具链**：无缝集成自己编写的 CLI 工具（如 `gitx`），打通 GitHub 工作流。
