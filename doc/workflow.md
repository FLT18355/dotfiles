# 我的Terminal工作流

**终端**: 使用的是*Konsole*
**配色方案**: 整体使用Catppuccin Mocha紫色调
**鼠标主题**: Cartoonish-Bold
**字体**: Maple Mono NF CN
**Shell**: Fish

- 工具:
  - yazi: 文件管理器
  - neko(FLT18355/neko): 音乐播放器
  - gitx-tui: 自己写的github TUI
  - starship: 美化命令行提示符
  - herdr: AI时代的tmux(TUI)
    - herdr-sidebar(侧边栏)
    - herdr.auto-title(自动标题)
  - tuios: 终端里面的窗口平铺器
  - atuin: 历史管理器
  - fzf/tv(television)
  
- 玩具:
  - metrocity(屏保) **cargo install metrocity**
  - pipes-rs

- 包管理器
  - Neoarch(sanjayadanushka712/Neoarch)
  - Homebrew
  - uv(Python)
  - bun(TS, JS)

- 代码编辑器
  - neovim(lazyvim) 已放弃
  - fresh(比neovim更快, 更好)
