# Oh-My-Pi (omp) 插件配置

这里记录了我当前 `omp` 环境启用的核心插件。

- **@izhimu/pi-caveman**
  野人模式，强制压缩 AI 输出，去掉废话，大幅节省 token。
  
- **gray-matter**
  Markdown 头部元数据解析，作为底层依赖使用。

- **pi-bansos**
  自动检测并剔除失效的模型 Provider 节点。

- **ponytail**
  防过度设计，强制 AI 遵循极简原则，少写不必要的代码。
  (omp plugin marketplace add DietrichGebert/ponytail, omp plugin install ponytail@ponytail)
